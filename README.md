# Aura Cover

Undercover en 3D entre potes : le roi vous a convoqués autour du feu de camp, des traîtres se cachent parmi vous.

## ⬇️ [Télécharger Aura Cover pour Windows](https://github.com/artercamille/auracover-jeu/raw/main/AuraCover.zip)

1. Dézippe et lance `AuraCover.exe`
   (si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*).
2. Installez tous **Radmin VPN** et rejoignez le même réseau.
3. L'hôte clique sur **Allumer un feu** et donne son IP (26.x.x.x) sur Discord, les autres la collent et cliquent sur **Rejoindre**.

Tout le monde doit avoir la même version : quand une nouvelle sort, un bouton rouge apparaît sur l'écran titre du jeu.
